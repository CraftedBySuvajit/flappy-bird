Flappy Bird

Created by Suvajit Ghosh

An advanced, feature-rich Flappy Bird clone built in Python with Pygame. Experience smooth gameplay, multiple difficulty levels, and a sleek high-score system.

How to Play

  1. Clone or download the repository from GitHub.
  2. Ensure you have Python 3.x installed.
  3. Install dependencies: pip install pygame
  4. Launch the game: python "flappy bird.py"
